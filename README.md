# Falling-Stars
The stars are falling from the sky! It's up to you to catch and save them

The background music is <a href = "https://opengameart.org/content/5-chiptunes-action">Level 3 from the 5 Action Chiptunes By Juhani Junkala on opengameart.org<a/>

The stars' sound effect when being caught is a cut version of:

### August 2024 Update:
This was my very first game project. Created during the 2020 Covid lockdown, I was able to learn a lot about SDL, colliders, and other aspects of making a game. Looking at it now, I feel the code could be cleaned up a bit, but I'm going to leave it as it is and retire this project.
